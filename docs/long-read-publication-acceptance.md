# long-read 对外发布验收

## 目标与边界

仅公众号、GitHub 和其他公开网页来源走 `public_wiki`；飞书文档和用户粘贴文本保持 `internal_only`。公开来源不等于已公开成功：只有无登录态访问实际页面成功，才可把链接发到群里。

## 验收矩阵

| 检查 | 证据 | 失败处理 |
| --- | --- | --- |
| 路由正确 | 来源被分为 `public_wiki` 或 `internal_only` | 停止，不创建或发送公开链接 |
| 知识库已发布 | `wiki spaces get` 返回 `open_sharing=open` | 停止，不创建页面 |
| 企业/知识库允许外发 | 管理员与知识库安全设置均允许外部分享 | 停止并请管理员开启 |
| 页面继承公开权限 | 页面分享面板没有“已限制权限，不再继承父级页面的权限” | 恢复继承，或把当前页设为“互联网获得链接的人 / 可阅读” |
| 内容写入正确 | `docs +update` 返回 `success` | 停止，不发送链接 |
| 匿名访问 | 无 Cookie 请求不跳转登录，且能读到本篇标题；有图片时图片也可读 | 发送无链接受阻卡片 |

## 当前验收结论（2026-07-16）

空间 `7663095985141796115` 已返回 `open_sharing=open`，测试页为该空间一级实体节点，底层 Docx 也显示 `external_access=true`、`link_share_entity=anyone_readable`。但无 Cookie 访问仍跳转飞书登录页，故匿名访问未通过；不能对外发送公开链接。

## 风险与回滚

- 公开网页来源仍可能含版权、个人信息或不应二次扩散的内容；生成前只发布精读，不复制整篇原文，且内部来源永不自动外发。
- 任何验收失败均 fail-closed：不发送链接，不把内部文档降级为公开文档。
- 紧急回滚只需由知识库管理员关闭“将知识库发布到互联网”；现有外部链接会立即失效。不要删除已生成页面，除非用户另行确认。
