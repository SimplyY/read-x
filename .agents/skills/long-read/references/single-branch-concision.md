# Read-X｜单分支分析精简规范

## 目标

在保留思想深度、证据与完整论证的前提下，
尽可能减少冗余，提高单次分析的信息密度。

篇幅由信息价值和论证复杂度决定，
不是越长越好，也不是越短越好。

## 生成规则

1. 先确定本分支必须回答的核心问题。
2. 优先保留决定性观点、证据、推理、反证与边界。
3. 同一观点原则上只解释一次。
4. 删除重复论述、冗长铺垫、套话、无增量总结和非必要举例。
5. 简单观点简写，复杂问题保留必要推导。
6. 不为追求简洁而删除独特洞察或重要信息。
7. 不补造事实、引文或证据。
8. 明确区分作者观点、原文事实与 AI 推断。

## 结构要求

- 遵守当前分析分支的专业任务及必要输出结构。
- 标题服务于真实思想结构，不机械增加层级。
- 不重复同一分支已经完成的论证。
- 如果没有其他分支的实际内容，不自行假设跨分支重复并删减重要信息。

## 篇幅原则

不设置统一的硬性总字数要求。
不采用截断或机械压缩。
优先减少低价值内容，而非缩短必要论证。

本指令作为实际发送给 ChatGPT 的生成约束，
而不是生成后的文本处理规则。

现有其他 Prompt 中如存在冲突的硬性篇幅要求，
必须在调用层统一处理，
不得将相互矛盾的要求同时交给模型。

## 输出检查

检查是否存在：
- 同义重复；
- 无信息增量的段落；
- 非必要的背景和举例；
- 因精简导致的关键证据、逻辑或边界缺失。

直接修正后输出最终分析正文。
