# content-scoring 维度锚点与校准

打分的可复现依据。每个维度 0~10 等级对应明确描述，打分先定位落哪档，附一句证据；分数由脚本算，不手算。维度是打分依据，不是输出字段。

## 长期价值 long_term_value

| 等级 | 描述 |
|------|------|
| 10 | 揭示可迁移的长期规律或结构性变化，5 年后仍成立 |
| 8 | 有明确的长期趋势判断，超出当下热点 |
| 6 | 涉及中期趋势，部分可迁移 |
| 4 | 停留当下事件，迁移性弱 |
| 2 | 纯即时信息，无长期价值 |
| 0 | 无价值或价值已失效 |

## 事实可靠 factual_reliability

| 等级 | 描述 |
|------|------|
| 10 | 一手数据/亲历，事实与观点严格分离，可独立核验 |
| 8 | 多数事实可核验，观点标注清晰 |
| 6 | 部分事实可核验，事实观点偶有混杂 |
| 4 | 多为转述，核验困难 |
| 2 | 大量不可核验陈述 |
| 0 | 已知失实或纯编造 |

## 洞察深度 insight_depth

| 等级 | 描述 |
|------|------|
| 10 | 完整因果 + 反馈 + 二阶影响，揭示系统演化 |
| 8 | 有因果链与二阶思考 |
| 6 | 有因果但缺二阶 |
| 4 | 现象罗列，因果弱 |
| 2 | 表层描述 |
| 0 | 无洞察 |

## 智慧迁移 wisdom_transfer

| 等级 | 描述 |
|------|------|
| 10 | 可沉淀为通用模型/原则/方法，跨域适用 |
| 8 | 可提炼为原则，限定域内通用 |
| 6 | 有可借鉴的做法 |
| 4 | 经验之谈，迁移性弱 |
| 2 | 个案无抽象 |
| 0 | 无可迁移内容 |

## 信息效率 information_efficiency

| 等级 | 描述 |
|------|------|
| 10 | 每句都是独立信息单元，零水分 |
| 8 | 核心密集，少量必要铺垫 |
| 6 | 骨架扎实，有一定水分 |
| 4 | 大量铺垫，核心稀薄 |
| 2 | 通篇水分，核心极少 |
| 0 | 纯水文 |

## 结构表达 structure_expression

| 等级 | 描述 |
|------|------|
| 10 | 论证闭环，结构自洽，边界自知 |
| 8 | 主线清晰，结构完整 |
| 6 | 有主线但略散 |
| 4 | 碎片拼凑 |
| 2 | 无结构 |
| 0 | 逻辑混乱 |

## 打分方法

1. 以主领域+次领域双重专家视角逐维度定位等级，附一句证据（禁通用套话）；
2. `base_score` 由脚本计算，禁止手算或自报分数；
3. 加分看读者相关性，扣分看风险，均在脚本 clamp；
4. 禁止为「安全」普遍给中间分；明确依据才能定档。

## 校准基准

抽象样本，用于对照，不指代具体文章：

- **9.0 稀缺精读**：六维度多数 10，一手数据 + 完整因果 + 可迁移模型，加分顶 1.0，无扣分。如某领域奠基者亲述的体系性判断。
- **8.0 完整深读**：多数维度 8，独立框架 + 信号密集，加分 0.7~1.0。如带一手细节的深度行业分析。
- **7.0 选择性深读**：多数维度 6~8，有价值但非体系性，加分 0.4~0.7。如质量不错的经验总结。
- **6.0 快速阅读**：多数维度 4~6，信息有用但增量有限，加分 ≤0.4。如行业常识汇编。
- **≤5.9 跳过**：维度多在 0~4，或核心扣分把分压到 6 以下。如通稿、水文、标题党。

## 偏差对抗

打分时主动对抗五大系统性偏差：

- 长度偏差：长文不自动高分，看信息效率
- 流畅偏差：文笔好不等于论证好，看事实可靠与洞察深度
- 权威偏差：大 V 大号不加基础分，只看内容本身
- 情绪偏差：让你激动不等于认知增量，看智慧迁移
- 确认偏差：符合你观点不加分，个人匹配只进加分项不进维度
