# content-scoring 维度锚点与校准

打分的可复现依据。每个维度 0~10 等级对应明确描述，打分先定位落哪档，附一句证据；分数由脚本算，不手算。维度是打分依据，不是输出字段。

## 长期价值 long_term_value

| 等级 | 描述 |
|------|------|
| 10 | 揭示可迁移的长期规律或结构性变化，5 年后仍成立 |
| 9 | 有明确的长期趋势判断，超出当下热点 |
| 8 | 涉及中期趋势，部分可迁移 |
| 6 | 停留当下事件，迁移性弱 |
| 3 | 纯即时信息，无长期价值 |
| 0 | 完全无价值或价值已失效 |

## 事实可靠 factual_reliability

| 等级 | 描述 |
|------|------|
| 10 | 一手数据/亲历，事实与观点严格分离，可独立核验 |
| 9 | 多数事实可核验，观点标注清晰 |
| 8 | 部分事实可核验，事实观点偶有混杂 |
| 6 | 多为转述，核验困难 |
| 3 | 大量不可核验陈述 |
| 0 | 已知失实或纯编造 |

## 洞察深度 insight_depth

| 等级 | 描述 |
|------|------|
| 10 | 完整因果 + 反馈 + 二阶影响，揭示系统演化 |
| 9 | 有因果链与二阶思考 |
| 8 | 有因果但缺二阶 |
| 6 | 现象罗列，因果弱 |
| 3 | 表层描述 |
| 0 | 无洞察 |

## 智慧迁移 wisdom_transfer

| 等级 | 描述 |
|------|------|
| 10 | 可沉淀为通用模型/原则/方法，跨域适用 |
| 9 | 可提炼为原则，限定域内通用 |
| 8 | 有可借鉴的做法 |
| 6 | 经验之谈，迁移性弱 |
| 2 | 个案无抽象 |
| 0 | 无可迁移内容 |

## 信息效率 information_efficiency

| 等级 | 描述 |
|------|------|
| 10 | 每句都是独立信息单元，零水分 |
| 8 | 核心密集，少量必要铺垫 |
| 6 | 骨架扎实，有一定水分 |
| 4 | 大量铺垫，核心稀薄 |
| 2 | 通篇水分，核心极少 |
| 0 | 纯水文 |

## 结构表达 structure_expression

| 等级 | 描述 |
|------|------|
| 10 | 论证闭环，结构自洽，边界自知 |
| 8 | 主线清晰，结构完整 |
| 6 | 有主线但略散 |
| 4 | 碎片拼凑 |
| 2 | 无结构 |
| 0 | 逻辑混乱 |

## 打分方法

1. 以主领域+次领域双重专家视角逐维度定位等级，附一句证据（禁通用套话）；
2. `base_score` 由脚本计算，禁止手算或自报分数；
3. 加分看读者相关性，扣分看风险，均在脚本 clamp；
4. 禁止为「安全」普遍给中间分；明确依据才能定档。
