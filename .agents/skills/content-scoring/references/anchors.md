# 七篇个人质量锚点

七篇仅校准 `quality_score`。评分时阅读正文证据并比较结构，不得按标题、URL 或锚点 ID 直接返回目标分。维度分集合和权重以 `scoring-policy.json` 为准。

## A1｜AI三问

- URL：https://mp.weixin.qq.com/s/YPWJphZUX7w1gLgEqG7I-w
- 三维：证据 `8.0`；洞察 `9.0`；迁移 `9.0`

核心主张：

1. C1 `causal`：AI 产业链的高利润率放大了金融市场影响。原文：“AI产业链的这一轮景气，带来了极高的利润率。”
2. C2 `method`：必须区分技术/产业成功与商业模式/金融泡沫。原文：“AI技术、AI产业的成功是一回事。AI商业模式、AI金融泡沫的破灭是另一回事。”
3. C3 `causal`：行业争抢的是未必存在的商业先发优势。原文：“我认为本轮AI投资来得太急，成本上升太快，似乎在争夺一个在商业模式上并不存在的先发优势。”
4. C4 `causal`：AI 资本开支规模和折旧结构可能超过最终客户利润池承载力。原文：“至少对于目前市场一致预期的，AI产业未来5年资本开支计划，我们可以断言其必定亏损。”
5. C5 `causal`：巨头投入由垄断业务被颠覆的恐惧和军备竞赛锁定驱动。原文：“因为被锁定在军备竞赛之中，所以规模只能越来越大，无论合理不合理。”

定级理由与上限：

- 证据（C1～C5）：跨市场、财务、产业和物理约束提供大量可追索数据与类比；部分关键数字和推断未在文内给出完整来源，因此止于 8.0。
- 洞察（C1、C3～C5）：把 K 形分化、折旧、循环融资和巨头博弈连成机制链；周期框架仍有较强作者假设，因此止于 9.0。
- 迁移（C2、C4、C5）：区分技术价值与商业回报、用总系统视角消除内部交易，可迁移到多数资本密集型浪潮；未达到普适标杆。
- 效率（C1～C5）：长文虽长但层层推进，仍有可压缩的历史铺陈和重复强调。
- 相邻区别：比 A6/A7 更宏观、更具系统约束；也因预测跨度和未经外部核验的推断，不能到 10.0。

## A2｜你不缺价值，你缺的是“确权”

- URL：https://mp.weixin.qq.com/s/EXrMpbj7L9JB-vMGzUVuWA
- 三维：证据 `7.0`；洞察 `7.0`；迁移 `8.0`

核心主张：

1. C1 `method`：价值是结构问题，价值感是体验问题。原文：“价值，是结构问题。”
2. C2 `causal`：价值太多太散会让动作失去排序依据。原文：“价值没有结构的后果是什么？是所有动作失去排序依据。”
3. C3 `causal`：把表达当成证明，会给动作附加价值感成本。原文：“每个动作都附带一份证明成本。”
4. C4 `method`：价值不清应以定义、取舍、定价、交付、验证解决。原文：“价值不清的唯一治法是结构动作：定义、取舍、定价、交付、验证。”
5. C5 `method`：付费、复购和转介绍构成比评价、自我认可更稳的市场确权。原文：“第三级，市场确权——有人付费、有人复购、有人转介绍。”

定级理由与上限：

- 证据（C1～C5）：三个咨询案例为经验证据，细节足以支持方法性判断；样本小且由作者单方解释，止于 7.0。
- 洞察（C1～C4）：区分结构病与感受病有效，但部分心理机制是强解释而非充分论证，止于 7.0。
- 迁移（C1、C4、C5）：诊断—对应动作框架可直接迁移到个人业务和职业转型，达到 8.0。
- 效率（C1～C5）：核心清楚，但品牌叙事、自我案例和重复总结增加阅读成本。
- 相邻区别：比 A3 更具市场验证闭环；不及 A5 的历史制度链和 A6 的工程化可检验性。

## A3｜你以为你想要自由，但你也许陷入了认知黑洞

- URL：https://mp.weixin.qq.com/s/FBcKA9I7ko1SSj_iOhoSCA
- 三维：证据 `6.0`；洞察 `8.0`；迁移 `8.0`

核心主张：

1. C1 `causal`：辞职并不自动产生自由。原文：“辞职就会有自由吗？”
2. C2 `method`：自由应定义为人与选择之间的位置关系。原文：“——你和你的选择之间的位置关系。”
3. C3 `causal`：未经审视的概念定义会生成行动瘫痪和焦虑。原文：“每一个"动弹不得"的背后，都站着一个没有被审视过的概念定义。”
4. C4 `method`：现实不变时，最小创造行动也能增加选择。原文：“每天15分钟，就可以开始一件全新的、甚至是全网空白的事情。”
5. C5 `normative`：自由的核心是在现实约束下仍保有创造性。原文：“真正的自由，不是想做什么就做什么，而是在任何现实条件下，你依然可以发挥你的创造性。”

定级理由与上限：

- 证据（C1～C5）：以个案、孩子故事和作品类比支撑，能说明体验但不能充分证明普遍因果，止于 6.0。
- 洞察（C1～C3、C5）：把“自由=辞职”改写为选择权与叙事权，形成清楚的认知重构，达到 8.0。
- 迁移（C2、C4、C5）：概念拆解、三次追问和 15 分钟行动可跨职业处境使用，达到 8.0。
- 效率（C1～C5）：主线反复出现，营销与系列说明明显拉长文章，止于 6.0。
- 相邻区别：比 A2 更偏哲学重定义、证据更弱；因此虽然洞察相近，总分略低。

## A4｜怎么看待“史上最大开源模型” Kimi K3？

- URL：https://mp.weixin.qq.com/s/7zgg6Vwre4jUbYr4fZyr1Q
- 三维：证据 `8.0`；洞察 `6.0`；迁移 `7.0`

核心主张：

1. C1 `empirical`：多项评测显示 K3 接近当时旗舰模型。原文：“根据多个国外机构的测试，以及我自己的测试（附在后文），我认为是真的。”
2. C2 `causal`：作者把能力跃升主要归因于总参数扩张。原文：“比起以前的版本，K3 最大不同就是参数数量从 1T 增加到了 2.8T，这大概就是它能力飞跃的原因。”
3. C3 `method`：MoE 稀疏激活降低了实际计算量。原文：“K3 的实际运算量并不像表面看上去那么大。”
4. C4 `empirical`：K3 定价和单任务成本仍然较高。原文：“Kimi K3 的使用成本还是很贵”
5. C5 `experiential`：四个横向任务中，K3 的实际表现不逊于比较对象。原文：“通过以上四个测试，可以看到，Kimi K3 的表现，完全不比那些旗舰模型逊色”

定级理由与上限：

- 证据（C1～C5）：引用公开榜单、价格、发布报告和可点击样例，文内支撑较强；个别参数推算和因果归因较粗，止于 8.0。
- 洞察（C2～C4）：主要是信息解释和体验比较，没有展开训练机制或商业二阶影响，止于 6.0。
- 迁移（C1、C3、C4）：提供读模型发布稿、稀疏度与成本的基本框架，达到 7.0。
- 效率（C1～C5）：结构清楚、问题式推进、实测集中，达到 8.0。
- 相邻区别：比 A2/A3 证据更硬、解释增量更浅；总体同属刚过 7 分锚点。

## A5｜西班牙传控体系发展史：从全能足球到 Tiki-taka

- URL：https://mp.weixin.qq.com/s/awZce2MbQCDdSxldlhrEWw
- 三维：证据 `8.0`；洞察 `8.0`；迁移 `9.0`

核心主张：

1. C1 `method`：全能足球的核心是动态控制空间与时间，而非固定阵型。原文：“全能足球的核心并非某种僵化的阵型，而是一种对“空间”与“时间”的极致操控”
2. C2 `causal`：阿贾克斯人才流失反而促成战术基因外溢。原文：“阿贾克斯的“失血”恰恰是全能足球基因向外扩散的开始。”
3. C3 `causal`：克鲁伊夫把个人天才转化为统一青训与战术生产线。原文：“克鲁伊夫改革的核心，是将分散且无法量化的天才贡献转化为可复制的制度性遗产。”
4. C4 `causal`：Tiki-taka 是应对密集防守和商业化确定性需求的战术演化。原文：“瓜迪奥拉时代传控足球的登峰造极，绝非单纯为了追求艺术美感，而是残酷竞技环境下的战术刚需。”

- 证据（C1～C5）：用球队、年代、战绩和制度变化形成历史链；部分文化决定论与因果归属缺少反例，止于 8.0。

- 迁移（C1、C3～C5）：从个人天才到可复制制度、从对抗到共同演化的模型跨组织适用，达到 9.0。
- 效率（C1～C5）：长历史叙事密度较高，但个别事实罗列和修辞可压缩，止于 7.0。
- 相邻区别：比 A4 多出制度演化和长期迁移，比 A6 的直接工程清单更慢但历史解释更完整。

## A6｜删掉 80% 的 Skill，Agent 反而更听话了

- URL：https://mp.weixin.qq.com/s/2tW8I_TjLk7dtzysGNs3hQ
- 三维：证据 `7.0`；洞察 `9.0`；迁移 `9.0`

核心主张：

1. C1 `causal`：Skill 膨胀会稀释关键规则的注意力。原文：“膨胀到 1500 行后，前 50 行没动，但后面多了 1400 行"中间内容"，注意力被严重稀释”
2. C2 `causal`：自动修复偏好追加，长期会把少量新知识放大成大量重复规则。原文：“每次发现 badcase，自动修复工具的处理方式几乎一模一样：生成一段新规则，追加到文档中。”
3. C3 `method`：把硬规则、方法、流程和模板分层，利用位置表达优先级。原文：“将 Skill 视为有层次结构的文档，位置决定优先级”
4. C4 `method`：用正向行为和显式适用范围消除否定指令与隐性冲突。原文：“当两条规则存在张力时，明确标注各自的适用范围”
5. C5 `method`：自动修复需要行数预算、语义去重、追加上限和定期压缩。原文：“如果你也用工具自动迭代 Skill，一定要加防膨胀机制”

定级理由与上限：

- 证据（C1、C2）：真实改造前后行数和案例支撑清楚，但研究数据来源与遵循率缺少完整引证，止于 7.0。
- 洞察（C1～C4）：把 badcase 修复从“补规则”提升为注意力、冲突和文档架构问题，达到 9.0。
- 迁移（C3～C5）：分层、去重、正向表达和膨胀刹车可直接迁移到多数提示词系统，达到 9.0。
- 效率（C1～C5）：问题—机制—八项解法—检查表组织紧凑，少量重复不影响 8.0。
- 相邻区别：比 A7 聚焦单一问题并给出更直接的可操作清单；证据严谨度不足使其未到 9 分。

## A7｜AI 写代码越来越快，慢下来的那个人变成了我

- URL：https://mp.weixin.qq.com/s/CXt_PIQAKVeskdNxAGFh3g
- 三维：证据 `8.0`；洞察 `9.0`；迁移 `9.0`

核心主张：

1. C1 `causal`：Agent 变快后，瓶颈从实现转向人如何定义继续行动的依据。原文：“瓶颈从"它会不会写"，变成了"我该让它根据什么继续写"。”
2. C2 `method`：Loop 必须让模型外反馈改变下一轮行动并包含停止条件。原文：“如果反馈能改变下一轮行动，并且知道什么时候该停，它才更接近我理解里的 Loop。”
3. C3 `method`：判断 loop 要追问目标、反馈来源、反馈距离、可用性和停止条件。原文：“判断一个 loop 靠不靠谱，我现在会先问五个问题”
4. C4 `causal`：错误 eval 会让系统稳定地把错误目标做完整。原文：“系统会稳定地把错误目标做完整，这种失败比直接报错更难排查。”
5. C5 `method`：Prompt 管起点，Loop 管过程校正。原文：“Prompt 更像起点，Loop 更像校正系统。”

定级理由与上限：

- 证据（C1～C5）：个人实践、代码反馈例子、三层反馈框架与失败模式互相支撑；外部框架引用未系统展开，止于 8.0。
- 洞察（C1、C2、C4、C5）：提出反馈距离、错误目标放大、人与 AI 不同时间尺度，形成完整二阶解释，达到 9.0。
- 迁移（C2、C3、C5）：四要素、五问、三层反馈和停止门可迁移到工程、自动化与产品迭代，达到 9.0。
- 效率（C1～C5）：篇幅与论证匹配，概念重复用于推进而非填充，达到 8.0。
- 相邻区别：比 A6 覆盖更完整的反馈系统和人机边界；仍以概念框架为主，未达到 10.0 的实证强度。

## A8｜《历史》的开篇是一出悲剧性的炫耀

- URL：https://mp.weixin.qq.com/s/nF3xUewQqSGrToq2FByT2w
- 三维：证据 `6.5`；洞察 `8.0`；迁移 `8.0`（质量 = 0.2×6.5 + 0.4×8.0 + 0.4×8.0 = 7.7，≥ 用户目标 7.5）
- 类型：哲理/思想类轨道（`reading_category=culture`）

核心主张：

1. C1 `causal`：人类冲突可能源于自我炫耀的本性。原文：“人类的冲突也许就来源于人类自我炫耀的本性。”
2. C2 `causal`：炫耀财富、权力、学识的冲动普遍存在于人性中。原文：“很多人都喜欢炫耀，炫耀自己财富、权力、学识等等”

定级理由与上限：

- 证据（C1～C2）：思辨自洽、立场诚实，属哲理类论证，不以实证数据立论，止于 6.5。
- 洞察（C1）：把人类冲突归因于炫耀本性，是对人性与冲突的深刻认知重构，非显然、间接，达到 8.0。
- 迁移（C1～C2）：关于人性与冲突的持久透镜，跨场景长期改变对人际、权力、舆论的看法，达到 8.0。
- 相邻区别：本锚点校准哲理/思想类轨道，验证「洞察/迁移不因间接性被压低」；比 A3 更偏人性因果、更不提供操作。

## 使用方式

1. 本文件只用于评分完成后的外部回归，质量模型禁止直接或间接读取。
2. `scripts/prepare_anchor_view.py` 只保留历史审计与测试用途，不进入生产评分链路。
3. 回归时每轮先 `/new`，模型只接收匿名正文和通用数值语义；本文标题、身份、目标区间和其他锚点均不得进入评分上下文。
4. 用户目标区间只由外部验收器在评分完成后比较，禁止反写进运行语义。
